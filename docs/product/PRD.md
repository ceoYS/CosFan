- 문서 버전: v0.4
- 문서 목적: CosFan의 축소된 MVP 범위, 수동 검증 기준, Web / No-code MVP, App MVP 기능, 권리 정책, 콘텐츠 등급, 미성년자 안전 정책, 혜택 제공/환불 정책, Unit Economics, GTM 전략, 장기 18+ 확장 전략을 정의한다.

## 1. Product Purpose

CosFan은 코스프레/서브컬처 크리에이터와 팬이 월 멤버십을 통해 지속적인 관계를 형성하는 모바일-first B2C 팬앱이다.

CosFan은 팬클럽 운영 SaaS가 아니다. 사용자가 인식하는 핵심 제품은 크리에이터 운영 도구가 아니라, 팬이 좋아하는 크리에이터를 구독하고 메시지, 룩북, 디지털 포토카드, 촬영회·행사 공지를 소비하는 팬앱이다.

MVP 공개 포지션은 “안전한 코스프레/서브컬처 팬 멤버십 앱”이다. 장기적으로 18+ 성인 미공개 콘텐츠 확장 가능성은 열어두되, MVP 공개 앱에서는 18+ 콘텐츠 판매를 지원하지 않는다.

## 2. Problem Definition

| 구분 | 현재 문제 | CosFan의 해결 방향 |
|---|---|---|
| 팬 | 좋아하는 크리에이터의 사진, 공지, 행사 정보를 여러 SNS에서 흩어져 확인해야 한다. | 크리에이터 프로필, 구독자 전용 룩북, 메시지, 공지를 한 앱에서 확인한다. |
| 팬 | 후원 또는 구독 이후 받는 혜택이 명확하지 않다. | 월 구독 가격별 혜택을 사전에 명시하고, 결제 전 잠금 혜택을 보여준다. |
| 팬 | 크리에이터를 특정 시점에 응원했다는 기록이 남지 않는다. | 디지털 포토카드를 멤버십 기록 오브젝트로 제공한다. |
| 크리에이터 | SNS DM, 폼, 메신저, 결제, 정산을 따로 운영해야 한다. | 월간 팬클럽 패키지를 템플릿화하고, 팬 구독 링크와 콘텐츠 전달 흐름을 제공한다. |
| 플랫폼 | 코스프레/서브컬처 카테고리가 성인 콘텐츠 앱으로 오인될 수 있다. | MVP에서는 18+ 콘텐츠 판매, 개별 유료열람 중심 판매, 실시간 개인 대화, 영상통화, 거래형 수집 기능을 제외한다. |
| 플랫폼 | 촬영회·행사 공지가 개인 간 만남 유도처럼 보일 수 있다. | 공개적으로 주최자, 일정, 장소, 참가 조건이 명시된 행사 공지만 허용한다. |

## 3. Target Users

### 3.1 Initial Beachhead

초기 내부 beachhead는 다음으로 한정한다.

> 한국 코스프레/촬영회 기반 크리에이터 중 SNS 팔로워 5,000~50,000명, 정기적으로 사진/룩북/행사 공지를 올리는 크리에이터.

| 기준 | 정의 |
|---|---|
| 지역 | 한국 |
| 1차 카테고리 | 코스프레/촬영회 기반 크리에이터 |
| 공개 표현 | 코스프레/서브컬처 크리에이터 |
| 팔로워 규모 | SNS 팔로워 5,000~50,000명 |
| 콘텐츠 활동 | 월 2회 이상 사진, 룩북, 촬영회·행사 공지 업로드 |
| 팬덤 특성 | 댓글, 저장, 공유, 행사 참여 등 반복 반응이 있는 팬층 |
| 수익화 가능성 | 월 구독 또는 유료 팬클럽 운영 의향 보유 |

### 3.2 2차 확장 타깃

| 타깃 | 확장 시점 | 비고 |
|---|---|---|
| 지하돌 | App MVP 이후 | 행사 공지와 팬 커뮤니케이션 니즈 검증 후 확장 |
| 서브컬처 크리에이터 | App MVP 이후 | 일러스트, 굿즈, 행사 기반 크리에이터 포함 가능 |
| 해외 코스프레 크리에이터 | Post-MVP 이후 | 결제, 정산, 언어, 정책 검토 필요 |
| 18+ 크리에이터 | Future 18+ Expansion | 메인 앱과 분리된 별도 검토 트랙 필요 |

### 3.3 팬 사용자

| 사용자 그룹 | 니즈 | 핵심 행동 |
|---|---|---|
| 코스프레 팬 | 좋아하는 크리에이터의 사진과 룩북을 정기적으로 받고 싶다. | 탐색 → 프로필 확인 → 월 구독 → 룩북 열람 |
| 행사 참여 팬 | 촬영회·행사 공지를 놓치지 않고 확인하고 싶다. | 공지 확인 → 외부 신청 링크 이동 |
| 고관여 팬 | 특정 시점에 크리에이터를 응원했다는 기록을 남기고 싶다. | 포토카드 수집 → 컬렉션 확인 → 공유 |
| 라이트 팬 | 결제 전 크리에이터와 혜택을 확인하고 싶다. | 무료 탐색 → 잠금 혜택 확인 → 구독 검토 |

## 7. MVP Scope

CosFan v0.4의 MVP 단계는 다음 5단계로 나눈다.

1. Manual Validation MVP
2. Web / No-code MVP
3. App MVP
4. Post-MVP
5. Future 18+ Expansion

### 7.1 Scope Summary

| 단계 | 목적 | 포함 범위 | 제외 범위 |
|---|---|---|---|
| Manual Validation MVP | 앱/웹 개발 전 결제 의향과 운영 가능성 검증 | 1~3명 크리에이터, 팬 100명 내외, 수동 멤버십 4주 운영 | 앱 개발, 자동 결제, 자동 정산 |
| Web / No-code MVP | 앱스토어 출시 전 팬 수요와 프로필/혜택 구조 검증 | 크리에이터 프로필 페이지, 혜택 소개, 대기/결제 의향 폼, 수동 포토카드 기록 | 네이티브 앱, 앱스토어 결제 |
| App MVP | 월 구독 팬앱의 핵심 루프 구현 | 가입, 탐색, 프로필, 월 구독, 룩북, 1:N 메시지, 포토카드, 공지, 신고/차단, 구독 관리 | 선물, 공개 순위형 랭킹, 이벤트 신청/결제/체크인 |
| Post-MVP | 매출 확장과 운영 효율화 | 디지털 선물, Supporter 기능 고도화, 이벤트 신청, 자동 정산 | 18+ 콘텐츠 |
| Future 18+ Expansion | ARPPU 상승을 위한 별도 사업 트랙 검토 | 별도 웹 영역, 연령 인증, KYC, 별도 결제사, 별도 검수 정책 | 메인 앱 내 18+ 노출 |

## 8. Manual Validation MVP

### 8.1 목적

앱과 웹을 만들기 전에 다음 4가지를 검증한다.

| 검증 항목 | 질문 | 통과 기준 |
|---|---|---|
| 크리에이터 공급 | 크리에이터가 CosFan형 월 멤버십 운영에 참여할 의향이 있는가? | 1~3명 실험 참여 |
| 팬 결제 수요 | 팬이 월 멤버십에 실제 결제하는가? | 팬 100명 내외 중 실제 유료 전환 15명 이상 |
| 운영 가능성 | 메시지, 룩북, 포토카드, 공지를 4주간 반복 운영할 수 있는가? | 주 1회 이상 콘텐츠 제공 |
| 유지 가능성 | 유료 전환자가 4주 후에도 지속 의향을 보이는가? | 실제 결제자 중 50% 이상 |

### 8.2 Manual Validation MVP 포함 범위

| 항목 | 내용 | 구현 방식 |
|---|---|---|
| 크리에이터 수 | 1~3명 | 직접 섭외 |
| 팬 규모 | 100명 내외 | 크리에이터 SNS 링크 기반 모집 |
| 유료 전환 목표 | 실제 유료 전환 20명 | 수동 결제, 예약, 폼 기반 의향 확인 |
| 운영 기간 | 4주 | 주간 운영표 기반 |
| 멤버십 운영 | 월 구독 혜택 수동 제공 | 카카오, 디스코드, 노션, 이메일, 폼 등 활용 |
| 룩북 제공 | 구독자 전용 이미지/링크 제공 | 노션, 비공개 링크, 이메일 등 |
| 메시지/공지 | 크리에이터 메시지와 행사 공지 발송 | 카카오 채널, 디스코드, 이메일 등 |
| 포토카드 | 월간 포토카드 수동 발급 | 이미지 파일 + 스프레드시트 발급 로그 |
| 결제 검증 | 결제 의향, 예약 신청, 실제 결제 분리 측정 | 예약 폼, 수동 결제, PG 테스트 등 |
| 정산 | 수동 정산 | 스프레드시트 기반 |
| 정책 운영 | 금지 콘텐츠/신고 접수 안내 | 운영자 수동 검토 |

### 8.3 Manual Validation MVP 크리에이터 최소 확인 기준

Manual Validation MVP부터 아래 항목을 확인한 크리에이터만 실험 참여 대상으로 선정한다.

| 확인 항목 | 기준 | 확인 방식 |
|---|---|---|
| 활동 SNS 계정 소유 확인 | 본인이 운영하는 활동 계정이어야 한다. | 계정 DM 인증, 프로필 링크 삽입, 이메일 확인 등 |
| 성인 여부 또는 계약 가능 여부 확인 | 유료 멤버십 운영 및 정산 계약이 가능한 상태여야 한다. | 신분/계약 가능 여부 확인. 세부 방식은 법무 검토 필요 |
| 정산 받을 계좌 명의 확인 | 정산 계좌 명의가 크리에이터 본인 또는 계약 주체와 일치해야 한다. | 계좌 정보 확인. 개인정보 보관 방식은 법무 검토 필요 |
| 업로드 콘텐츠 권리 보유 확인 | 촬영 권리, 초상권, 배포권, 제3자 촬영자 허락 여부를 확인해야 한다. | 권리 보유 체크박스 및 필요 시 소명 자료 요청 |
| MVP 금지 콘텐츠 정책 동의 | 18+ 판매, 성매매/만남 유도, 비동의 콘텐츠, 미성년자 관련 성적 콘텐츠 금지에 동의해야 한다. | 정책 동의 체크 및 기록 보관 |

## 9. Web / No-code MVP

### 9.1 목적

Web / No-code MVP는 앱스토어 출시 전 수요를 검증하기 위한 중간 단계다. Manual Validation MVP가 운영 가능성을 검증한다면, Web / No-code MVP는 크리에이터별 프로필, 혜택 소개, 팬 대기/결제 의향 수집, 포토카드 발급 기록을 제품 형태에 가깝게 보여주는 단계다.

### 9.2 포함 기능

| 기능 | 설명 | 구현 방식 |
|---|---|---|
| 크리에이터 프로필 페이지 | 크리에이터 소개, 대표 이미지, SNS 링크, 혜택 안내 | 노션, Framer, Webflow, 자체 랜딩 |
| 멤버십 혜택 소개 | 가격대별 혜택, 제공 주기, 유의사항 표시 | 랜딩 섹션 |
| 팬 대기/결제 의향 폼 | 팬 이메일, 관심 크리에이터, 가격대별 의향 수집 | Google Form, Tally, Typeform |
| 수동 포토카드 발급 기록 | card_id, creator_id, issue_month, holder_alias 기록 | 스프레드시트 |
| 운영자 수동 콘텐츠 등록 | 룩북/공지/메시지를 운영자가 대신 등록 | 노션 CMS, Airtable |
| 앱스토어 출시 전 수요 검증 | 앱 설치 없이 프로필 방문 → 의향 폼 전환 측정 | UTM, 초대 링크 |

### 9.3 Web / No-code MVP 성공 기준

| 지표 | 목표 |
|---|---:|
| 앵커 크리에이터 프로필 페이지 | 3~5개 |
| 크리에이터별 초대 링크 클릭 | 크리에이터당 100회 이상 |
| 프로필 방문 → 대기 등록 전환율 | 10% 이상 |
| 대기 등록 → 결제 의향 전환율 | 30% 이상 |
| 결제 의향 → 예약 신청 전환율 | 70% 이상 |
| 포토카드 수동 발급 기록 정확도 | 100% |
| 운영자 콘텐츠 등록 소요 시간 | 콘텐츠 1건당 10분 이하 |

### 10.1 App MVP 포함 기능

| 구분 | 기능 | 설명 |
|---|---|---|

| 탐색 | 크리에이터 탐색/프로필 | 크리에이터 리스트, 프로필, 월 구독 혜택 확인 |

## 11. Non-goals

| Non-goal | 설명 |
|---|---|
| 팬클럽 SaaS | CosFan은 크리에이터 운영 도구가 아니라 팬이 구독하고 소비하는 B2C 팬앱이다. |
| 성인 콘텐츠 앱 | MVP 공개 앱에서는 18+ 콘텐츠 판매를 지원하지 않는다. |
| 개별 유료 사진 판매 앱 | MVP의 핵심 수익은 월 구독이다. |
| 실시간 개인 대화 앱 | 메시지는 크리에이터 1:N 채널이다. |
| 데이팅 앱 | 매칭, 만남 유도, 영상 연결 기능을 제공하지 않는다. |
| 사적 만남 중개 | 개인 간 비공개 만남, 대가성 만남, 1:1 사적 약속을 중개하지 않는다. |
| 거래형 수집 앱 | 포토카드의 판매, 교환, 가격 표시, 투자성 표현을 제공하지 않는다. |
| 과금 압박형 앱 | 결제는 프로필, 잠금 혜택, 멤버십 시트에서만 발생한다. |

## 12. Core User Flows

### 12.1 팬 가입 → 탐색 → 구독

| Step | 화면 | 사용자 행동 | 시스템 동작 | UX 조건 |
|---|---|---|---|---|
| 1 | 스플래시 | 앱 실행 | 서비스 소개 표시 | 안전한 팬 멤버십 톤 |
| 2 | 회원가입 | 이메일/소셜 로그인 | 계정 생성 | 결제 요구 없음 |
| 3 | 온보딩 | 관심사 선택 | 추천 기준 저장 | 코스프레/서브컬처 중심 |
| 4 | 탐색 | 크리에이터 확인 | 리스트/검색/카테고리 표시 | 무료 탐색 가능 |
| 5 | 프로필 | 혜택과 가격 확인 | 월 구독 CTA 표시 | 신고/차단 1탭 접근 |
| 6 | 멤버십 시트 | 가격, 혜택, 갱신일 확인 | 결제 확인으로 이동 | 해지 방법 표시 |
| 7 | 구독 완료 | 결제 완료 | 구독자 권한 부여 | 구독 관리 접근 제공 |

### 12.2 구독자 전용 룩북 열람

| Step | 화면 | 사용자 행동 | 시스템 동작 |
|---|---|---|---|
| 1 | 크리에이터 프로필 | 룩북 탭 진입 | 공개/잠금 상태 표시 |
| 2 | 룩북 리스트 | 콘텐츠 선택 | 구독 상태 확인 |
| 3 | 룩북 상세 | 이미지 열람 | 조회 이벤트 기록 |
| 4 | 반응 | 리액션 입력 | 콘텐츠 반응 집계 |

### 12.3 크리에이터 1:N 메시지

| Step | 화면 | 사용자 행동 | 시스템 동작 | 제한 조건 |
|---|---|---|---|---|
| 1 | 메시지함 | 크리에이터 채널 선택 | 메시지 리스트 표시 | 온라인 상태 없음 |
| 2 | 메시지 상세 | 메시지 확인 | 열람 이벤트 기록 | 읽음 표시 없음 |
| 3 | 리액션 | 이모지 반응 | 반응 집계 | 과금 없음 |
| 4 | 짧은 답장 | 제한 길이 답장 작성 | 답장 저장 | 답변 보장 문구 없음 |
| 5 | 신고/차단 | 신고 또는 차단 선택 | 운영자 검토 또는 차단 처리 | 1탭 접근 |

### 12.4 포토카드 수집

| Step | 화면 | 사용자 행동 | 시스템 동작 |
|---|---|---|---|
| 1 | 컬렉션 | 보유 포토카드 확인 | 크리에이터/시리즈/월별 정렬 |
| 2 | 포토카드 상세 | 카드 선택 | 이미지와 발급 정보 표시 |
| 3 | 공유 | 공유 가능 카드 선택 | 워터마크 상태와 공유 권한 확인 |
| 4 | 기록 확인 | 획득 경로 확인 | 멤버십 기록으로 표시 |

### 12.5 촬영회·행사 공지

| Step | 화면 | 사용자 행동 | 시스템 동작 |
|---|---|---|---|
| 1 | 크리에이터 프로필 | 공지 탭 선택 | 촬영회·행사 공지 리스트 표시 |
| 2 | 공지 상세 | 주최자, 일정, 장소, 참가 조건, 안내 확인 | 외부 링크 표시 |
| 3 | 외부 이동 | 신청 링크 선택 | 외부 브라우저 또는 인앱 브라우저 이동 |
| 4 | 주의 안내 | 외부 신청/운영 범위 확인 | CosFan 관리 범위 안내 |

MVP에서는 촬영회·행사 공지와 외부 링크까지만 제공한다. 신청 관리, 결제, 체크인, 참가 카드는 Post-MVP로 이동한다.

허용되는 행사는 공개적으로 주최자, 일정, 장소, 참가 조건이 명시된 촬영회·행사·팬미팅 공지로 제한한다. 개인 간 비공개 만남, 대가성 만남, 1:1 사적 약속, 성적 서비스를 암시하는 만남 유도는 금지한다.

## 14. Digital Photocard Definition

### 14.1 정의

포토카드는 거래 가능한 자산이 아니라, 팬이 특정 시점에 크리에이터를 응원했다는 멤버십 기록이다.

CosFan의 디지털 포토카드는 단순 이미지 파일이 아니다. 포토카드는 발급 시점, 크리에이터, 시리즈, 획득 경로, 공유 가능 여부를 가진 팬덤 기록 오브젝트다.

### 14.2 Photocard Object Fields

| Field | Type | 설명 | 예시 |
|---|---|---|---|
| card_id | string | 포토카드 고유 ID | `card_2026_05_0001` |
| creator_id | string | 발급 크리에이터 ID | `creator_001` |
| series_name | string | 카드 시리즈명 | `May Lookbook` |
| card_number | string | 시리즈 내 카드 번호 | `03/10` |
| issue_month | string | 발급 월 | `2026-05` |
| issued_at | datetime | 실제 발급 시각 | `2026-05-28T12:00:00+09:00` |
| acquisition_source | enum | 획득 경로 | `monthly_membership`, `event_notice`, `manual_grant` |
| holder_alias | string | 보유자 표시명 | `YS_fan` |
| watermark_state | enum | 워터마크 상태 | `visible`, `hidden`, `creator_mark` |
| share_permission | enum | 공유 가능 범위 | `private`, `shareable_image`, `shareable_link` |
| transferability | enum | 양도 가능 여부 | `non-transferable` |
| market_value | enum | 시장 가치 표시 여부 | `none` |

### 14.3 Photocard UX Rules

| 원칙 | 설명 |
|---|---|
| 거래 기능 없음 | 판매, 교환, 양도, 가격 표시 기능을 제공하지 않는다. |

## 17. Unit Economics

### 17.1 Unit Economics 구조

월 구독 1건 기준 Unit Economics는 다음 구조로 계산한다.

| 항목 | 설명 | 계산 예시 |
|---|---|---|
| 팬 결제액 | 팬이 월 구독으로 결제한 총액 | ₩9,900 |
| 앱스토어/결제 수수료 | 앱스토어 또는 결제사가 차감하는 수수료 | 팬 결제액 × 수수료율 |
| 환불/세금/운영 비용 | 환불, 부가세, 고객지원, 모더레이션, 결제 실패 대응 비용 | 팬 결제액 × 운영 비용률 |
| 크리에이터 정산액 | 크리에이터에게 지급되는 금액 | 순매출 × 크리에이터 배분율 |
| CosFan 실수익 | 수수료와 비용 차감 후 CosFan에 남는 금액 | 순매출 - 크리에이터 정산액 - 운영 비용 |

## 25. Future 18+ Expansion Strategy

### 25.1 사업적 관점

18+ 성인 미공개 콘텐츠는 CosFan의 장기 ARPPU 상승 축이 될 수 있다. 다만 이는 메인 앱의 MVP 범위가 아니라, 별도 검토 트랙으로 분리해야 한다.

| 리스크 | 가능성 | 영향도 | 대응 |

| 개인 간 비공개 만남 유도 | 중간 | 높음 | 외부 링크/문구 검수, 신고 시 즉시 숨김 |
| 앱스토어 UGC 심사 리스크 | 높음 | 높음 | 신고/차단/모더레이션/운영자 연락 수단 제공 |
| 결제 정책 리스크 | 중간 | 높음 | 앱 내 디지털 구독 결제 정책 검토 |

| 촬영자/초상권 분쟁 | 중간 | 높음 | 업로드 전 권리 보유 체크박스와 소명 절차 운영 |

| 팬 구독 후 혜택 불만 | 중간 | 높음 | 결제 전 혜택/갱신일/해지 방법 명시, 환불/보상 기준 마련 |
| 메시지가 실시간 대화로 오인 | 중간 | 중간 | 타이핑/읽음/온라인 상태 제거 |
| 포토카드가 거래형 자산으로 오인 | 중간 | 중간 | 양도/판매/가격/교환 기능 미제공 |
| 공개 순위형 랭킹 과열 | 중간 | 중간 | MVP 제외, Supporter Badge/Fan Streak로 대체 |
| 이벤트 기능 범위 확대 | 중간 | 중간 | MVP는 공지와 외부 링크까지만 제공 |
| 외부 결제 우회 | 중간 | 높음 | 외부 링크 정책과 운영자 검수 적용 |
| 자동 정산 복잡도 | 중간 | 중간 | Manual Validation과 App MVP 초기는 수동 정산 |
| 18+ 확장으로 브랜드 혼선 | 중간 | 높음 | 별도 웹/인증/결제/검수 트랙으로 분리, 3~6개월 이상 운영 후 검토 |
