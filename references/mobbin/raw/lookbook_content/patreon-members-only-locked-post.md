# Reference: Patreon - Members-only locked post (inline lock state + "become a patron")
- source_app: Patreon (iOS)
- mobbin_category: Creator membership / gated content state
- screen_type: Post list (and post card) for a non-member, where exclusive posts show a locked media thumbnail and a membership CTA
- target_cosfan_screen: Members-only post in a non-member / locked presentation (drives membership, not per-item purchase)
- user_job: "I can see this creator has exclusive stuff; tell me how to get in (once), not nickel-and-dime me per photo."
- first_visible_promise: A real post card — title, creator, and a thumbnail that is clearly locked (a padlock glyph over a blurred/branded media tile). You see THAT exclusive content exists and is desirable, but the pixels are withheld. Above the list sits a single "become a patron" button.
- primary_cta: "become a patron" (full-width, top of the creator page) — one membership action that unlocks the WHOLE feed.
- secondary_cta: Tabs "Posts / Membership" to inspect tiers; tapping a locked post also routes to the join flow. A companion screen frames it as "By becoming a patron, you'll instantly unlock access to 5 exclusive posts".
- section_order: 1) creator cover + "become a patron" button -> 2) Posts / Membership tabs -> 3) search posts -> 4) post cards each = creator avatar + date + title + caption snippet + locked media thumbnail (padlock) + muted action row (lock/like/comment/share) -> 5) (sibling screen) "unlock access to N exclusive posts" tally.
- first_visible_promise_note: The lock is on the MEDIA, but the framing copy and CTA are about JOINING the creator, never "buy this one photo".
- trust_elements: Real post titles and captions are visible (proof the content is substantive), a count of how many posts you'd unlock ("5 exclusive posts"), creator identity and post cadence visible, tiers listed transparently with prices and perks.
- friction_removed: One CTA unlocks everything (no per-post checkout), the value is quantified ("unlock 5 posts") so the ask feels worth it, locked cards still show enough (title/caption) to build desire without exposing the asset.
- empty_loading_error_handling: Locked thumbnails act as a deliberate "withheld" state rather than an error; blurred/branded placeholder communicates "members only" clearly, not "broken image".
- monetization_exposure: HIGH but correctly framed — this screen's whole job is conversion, yet it sells MEMBERSHIP (a relationship + the full feed), not a single asset. There is no "$X to unlock this photo". This is the exact distinction CosFan must hold: gate -> join the creator, never gate -> buy this item.
- onboarding_step: Conversion step (non-member browsing -> join). Not first-run onboarding.
- mobile_pattern: Padlock overlay on media thumbnail, locked post card with visible metadata, single sticky membership CTA, value-tally microcopy ("unlock N posts").
- why_relevant_to_cosfan: Directly models CosFan's members-only post in its LOCKED state. The post card GIVES enough (title, caption, creator) to create desire; the padlock SIGNALS exclusivity; the single "become a patron" / value-tally PERSUADES via one clean membership decision. The fear removed: "is this an endless pay-per-tap trap?" — answered by one membership unlocking the whole feed and quantifying the reward. CosFan reuses this to present locked lookbooks as "join [creator]'s membership to see this + everything", reinforcing collectible-club belonging over transactional PPV.
- what_to_learn: Show locked content's metadata (title/caption/thumbnail-with-lock) to build desire without revealing the asset; quantify the unlock ("see N posts"); route every locked tap to ONE membership join, not a per-item checkout; keep the locked thumbnail a clear "members only" state, not an error.
- what_not_to_copy: Patreon's "become a patron" wording, its lock-glyph and blur styling, the orange brand mark, and the tier-table density. Re-skin the lock state to pastel collectible (a soft frosted card / cute lock), and write CosFan's own membership-belonging copy.
- risk_notes: CRITICAL — never let the locked state read as "unlock this photo for $X" or "tip to see". The CTA must always be membership/join-the-creator. Avoid any per-image price tag. Avoid blur that reads as adult/PPV teaser; keep it a clean "members only" frosted state, cute and collectible, not titillating.
- MVP_action: For non-members, render members-only posts as cards showing title + caption snippet + frosted/locked thumbnail with a soft lock badge, plus a single membership CTA ("Join [creator] to unlock"). Add a value tally ("Members see N posts"). Every locked tap -> the creator's membership/tier sheet, never a per-item purchase.
