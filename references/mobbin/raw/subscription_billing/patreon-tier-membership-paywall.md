# Reference: Patreon - Tier membership paywall (Join tier to unlock member content)
- source_app: Patreon
- mobbin_category: Subscription / Billing — creator membership paywall
- screen_type: Tier detail / paywall ("Tiers" list, each tier with Join CTA + benefits)
- target_cosfan_screen: Subscription / paywall sheet for a single creator (subscribe to unlock member-only content)
- user_job: "Show me what I get if I support this specific creator, at what monthly price, so I can decide if this tier is worth it."
- first_visible_promise: Tier name + price-per-month immediately under the header ("Pilot — $13 per month • 8 patrons"); a short plain-language description of what the tier is, then a bulleted benefit list.
- primary_cta: Full-width "Join $13 tier" button (price embedded in the CTA so there is zero ambiguity about what is charged).
- secondary_cta: Inline text link "or save 16% if you pay annually" directly under the Join button — upsell is offered, not forced, and stated as a saving.
- section_order: (1) Header / creator name → (2) Tier name + price/month + social proof ("8 patrons") → (3) optional tier artwork → (4) plain-language tier description → (5) primary "Join $X tier" CTA → (6) annual-save secondary link → (7) bulleted benefit list (Patreon-Only Updates, Q&A's, Early Access, % off merch) → (8) "Includes Discord benefits" footnote with platform icon.
- trust_elements: Patron count as social proof ("8 patrons"), price stated twice (header + CTA), benefits enumerated as concrete bullets rather than vague promises, annual option framed as a transparent saving %.
- friction_removed: No separate "see pricing" tap — price is in the header and on the button; benefits are scannable bullets; the annual upsell sits inline so the fan never has to hunt for the cheaper option.
- empty_loading_error_handling: Checkout variant ("Patron Checkout") is a clean card with price + "(+GST)" tax disclosure + Join, plus a "Show more" expander for long benefit lists so the card never overflows.
- monetization_exposure: High and per-tier, but honest: the charge is a clear recurring monthly membership (not a one-off per-post unlock). Tax ("+GST") is disclosed pre-purchase.
- onboarding_step: Reached from a creator's page when a fan chooses to support; not part of app onboarding.
- mobile_pattern: Stacked tier cards each with embedded-price CTA + benefit bullets + social-proof count; inline annual-save link; "Show more" expander on checkout.
- why_relevant_to_cosfan: This is the canonical fan-membership paywall and CosFan's closest analog ("Bubble + Patreon"). The screen "says": here is the creator, here is the monthly price, here is exactly what you unlock, here are others already supporting. Persuasion comes from concrete benefits + patron count, not urgency or scarcity. Placement (price in header AND button) removes price anxiety. Reusable wholesale as the subscribe-sheet skeleton; the embedded-price CTA is a must-adopt honesty pattern.
- what_to_learn: Put the exact monthly price inside the subscribe button; list benefits as concrete bullets tied to CosFan value (member lookbooks, digital photocards, member channel, early event access); offer annual as an inline saving; show a soft social-proof count; disclose tax before purchase.
- what_not_to_copy: Patreon's brand red/blue tier buttons, creator-uploaded banner art treatment, and "Discord benefits" framing. Do NOT inherit Patreon's text-heavy, low-polish density — CosFan is clean white pastel with practical (not cramped) density. Avoid wording that reads like one-off content unlock.
- risk_notes: Benefit bullets must describe recurring membership value, not "pay to see this one photo" — that drifts toward PPV/adult-PPV territory CosFan must avoid. Keep benefits truthful (no implying private 1:1 access). Photocard benefit must read as collectible, not as a tradable NFT asset.
- MVP_action: Build the subscribe sheet as: creator mini-header → tier name + "$X / month" → 1-line description → "Join — $X/mo" pastel CTA → "Save X% with yearly" inline link → benefit bullets (member feed, monthly digital photocard, member channel, early event notice) → tax/renewal fine print. One tier for MVP; design supports 2-3.
