# Reference: Instagram - Broadcast channel feed (creator 1:N to fans)
- source_app: Instagram (iOS)
- mobbin_category: Messaging / Broadcast channels
- screen_type: One-to-many broadcast message feed (creator posts, members read + react), with join/notification gate
- target_cosfan_screen: 1:N creator message channel (Bubble-style update feed)
- user_job: As a fan, I want to read short photo/text updates from a creator I follow and react lightly, without it being a two-way DM.
- first_visible_promise: Header shows the channel name ("Restaurants" / bonappetitmag, verified tick) and member count ("14.8K members"), instantly signaling "this is a public-ish broadcast many fans follow," not a private 1:1 chat.
- primary_cta: "Join" (enters the broadcast and enables notifications)
- secondary_cta: "Decline" (dismiss without joining); per-message emoji reaction chips; tap a creator message to react
- section_order: 1) Channel header (name + verified + member count) -> 2) Scrollable broadcast feed of creator messages, each as a left-aligned bubble with timestamp dividers ("OCT 26 AT 04:19") -> 3) Per-message reaction tallies (heart 78, laugh 21, etc. with "+4") -> 4) Occasional "creator replied to <fan>'s response" quote block -> 5) "Seen by 7.1K" read-count under latest -> 6) Bottom join bar with explainer + Decline/Join.
- trust_elements: Verified badge on creator; member count; "Seen by 7.1K" social proof; explainer copy "Anyone can join this broadcast channel created by bonappetitmag. If you join, this channel will be added to your inbox and you'll be able to receive notifications." sets clear, honest expectations.
- friction_removed: No compose box for fans on entry (read-first, low pressure); join is a single tap; reactions are one-tap emoji, no typing required; explainer pre-answers "what happens if I join?" removing hesitation.
- empty_loading_error_handling: Not shown on this screen; feed loads as standard chat list (infinite scroll upward through history).
- monetization_exposure: None on this screen — broadcast is free-to-join here; membership/paywall is decoupled from the channel surface.
- onboarding_step: Acts as a soft join step — the Decline/Join bar is effectively the channel's onboarding gate before notifications begin.
- mobile_pattern: Chat-style bubble feed; date-divider chips; reaction chips with overflow "+N"; sticky bottom action bar; quoted-reply block for creator-to-fan acknowledgement.
- why_relevant_to_cosfan: This is the closest real-world match to CosFan's message channel. The header (name + member count) PERSUADES via scale ("many fans already here"); placed top so a fan immediately understands the 1:N broadcast nature, reducing the fear of an awkward fake 1:1 paid chat. The read-first feed with one-tap reactions drives the exact light engagement CosFan wants. Highly reusable: bubble feed + date dividers + reaction tallies + a "Seen by" count.
- what_to_learn: The honest join explainer is the key lesson — it removes the fear "am I committing to spam / a private obligation?" by stating exactly what joining does (inbox + notifications). Reactions as the primary fan action (not replies) keep it a broadcast, not a chat. CosFan should reuse the member-count + verified header and the per-message reaction tally, restyled in Cool Pastel Collectible OS (white-first, pastel reaction chips).
- what_not_to_copy: Instagram's dark-on-photo treatment, exact emoji set, exact bubble styling, and "Decline/Join" wording. Do not import the "reply to your response" mechanic if it risks reading as 1:1; keep fan input to reactions for MVP. Never copy the brand mark or the "members" label verbatim.
- risk_notes: SAFE pattern — no voice/video/live/call/presence elements present on this screen. Watch that CosFan's version does NOT add green online dots or "active now"; keep it asynchronous. Ensure fan replies (if ever enabled) cannot be mistaken for paid private chat — gate or hide fan compose by default.
- MVP_action: Build the channel as a white-first bubble feed: creator messages left-aligned with pastel timestamp dividers, one-tap pastel reaction chips with "+N" overflow, and an optional "Seen by N" count. Gate entry with a short, honest "Join to get updates & notifications" sheet (reuse the explainer pattern, reworded). Default fans to read+react only; no compose box, no presence indicators. This drives the light-engagement broadcast behavior without any DM/dating/live risk.
